補足:
- FastAPI（Railway $5/月）は本番 Web 構成 B · C に含む。影響が小さいため、本番 Web 採用時は使う前提。
- A: Vercel · Supabase は無料枠。Excel 変換は作者 PC（exe）→ Web は import.json のみ。現状の運用に近い。
- B: ログイン · ユーザー管理 · クラウド保存を Supabase で行う標準構成。
- C: ログイン不要の場合。DB は Neon 等の安価プラン（$0〜19）を想定。ユーザー別データ分離は別途設計。
- D: クラウド不使用。Windows + Excel 必須。選定時の上司認識に近い。
