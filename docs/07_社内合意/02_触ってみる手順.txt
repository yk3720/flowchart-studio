================================================================================
今できる操作（PoC · 現状 · 約5分）
================================================================================

1. 上記 URL を開き、管理者アカウントでログインする

2. 「作る」操作を試す
   - 表ペインに CSV/表データを貼り付け（Ctrl+V）
   - 「再生成」でフロー図が更新されることを確認

3. 出力を試す
   - PNG または SVG で画像出力
   - （保存済みフローがあれば）一覧から開き直す

================================================================================
構成 B 採用時に追加される操作（現状は未デプロイ）
================================================================================

現状は作者 PC の変換 exe で import.json を作り、Web では JSON のみ取込可能。

・画面が真っ白 → ブラウザを Chrome/Edge 最新版で再試行
・その他 → 面談時に一緒に確認
