【お願い（結論）】
フローチャート作成ツール（Flowchart Studio）の本番運用について、次の3点をご判断ください。
1. 有償クラウド（月 約 $50 · 構成 B）の利用可否
2. 社内設計データ（社内番号 · 装置名 · PLCコメント等）の外部クラウド保存可否
3. 本番化時のサービスアカウント名義（個人 → 会社）の取得可否

※ 生成 AI（Copilot 等）の利用規程とは別議題です（本資料はホスティング・DB の話）。

【調査結果（1行）】
表駆動 Web 版の叩き台は完成。本番運用の推奨は構成 B（月 $50）。現状の $0 公開は検証用 PoC。

【作成者の推奨】
構成 B — Vercel Pro + Supabase Pro + FastAPI（Railway）。正式運用ならログイン認証あり。

【構成 B を推奨する理由（調査結果に基づく）】
1. 現行 Web 版（表駆動 · 自動レイアウト）に FastAPI を組み込み、ブラウザから装置 xlsx 変換まで完結できる
2. 会社として正式ツールとして運用するならログイン · ユーザー管理が必要（共用 admin は検証用のみ）
3. FastAPI（Railway）は月 $5 程度と追加コストが小さい — Web 本番では採用する前提
4. PLC コメントとフローチャートは対応づけて管理する必要があり、クラウド保存 · 認証付き Web が前提になる
5. 上記を満たす推奨構成は完全無料では実現できない — 有償 SaaS 利用の判断が必要
6. 年度テーマ（1装置分 · 実用化）に向け、PoC（構成 A）から本番（構成 B）への移行が自然

【Web版を選んだ理由（デスクトップ Excel+オートシェイプとの比較 · 調査結果）】
1. 所在 — Web に集約 · アプリを開けばデータにアクセス。Excel 貼付はシートを圧迫し管理が煩雑
2. 探索 — 作っても場所がわからなくなる · 他者のフロー参照も困難。DB 保存で共有が容易
3. 作図工数 — Excel オートシェイプは削除 · 貼付の手間大。Web は表編集 → 再生成で短い
4. 配布 · 版管理 — デスクトップは配布 · バージョン揃えが大変。Web は一箇所修正で全員が即利用

詳細: 03_調査報告_詳細.txt §2「Web版を選んだ理由」

================================================================================
1. 調査の目的
================================================================================

個人テーマ「フローチャート作成ツール実用化」について、どの運用構成がよいかを調査した。
現フェーズは「調査・検証」。方針確定後に開発を進める。

================================================================================
2. 現状（PoC · 構成 A 相当）
================================================================================

・Web 版の基本機能は実装済み（表編集 · 図プレビュー · 保存 · PNG/SVG · ログイン）
・Vercel + Supabase 無料枠で公開中（月 $0）
・FastAPI は未デプロイ（Excel 変換は作者 PC の exe → import.json 取込）
・本番 URL で管理者アカウントにより触れる状態

注意: 無料枠のまま本番運用する想定ではない。
  - Supabase: 1週間非アクセスで DB 一時停止 · 自動バックアップなし
  - Vercel Hobby: 非商用・個人向け（有給業務での継続利用は規約上グレー）
  → 課内正式運用には構成 B を推奨

================================================================================
3. 運用構成（4択 · 月額目安）
================================================================================

構成 | 内容 | 月額 | 位置づけ
-----|------|------|----------
A | 無料枠 · FastAPI なし | $0 | 現状 · 検証用 PoC
B | 本番 · 認証あり · FastAPI あり | $50〜 | 推奨 · 本番運用
C | 本番 · 認証なし · FastAPI あり | $25〜35〜 | 低コスト Web（アクセス制御は別途）
D | デスクトップ（Python+Excel） | $0 | 選定時想定 · Web 資産は別途判断

※ $50 = Vercel Pro $20 + Supabase Pro $25 + Railway $5（1席 · 1 DB · 軽量 API 想定の下限）
※ 為替 1$=150円 · 従量超過 · Vercel 追加席 +$20/席 は別途
※ 詳細試算: 03_調査報告_詳細.txt · 04_提案_2026-07-05_上司確認_運用方針とランニングコスト.txt

上司への主たる判断: 無料（A/D）か 有償 Web 本番（B/C）か の二択。
ログインあり/なし（B/C）の差は月 $15〜25 程度 · 面談で相談可。

4. 利用サービス（4つ）
================================================================================

サービス | 一言（制御設計へのたとえ） | Studio での役割 | 使う構成
---------|---------------------------|-----------------|----------
GitHub | 設計データのフォルダ＋変更履歴 | ソースコード保管 · Vercel 自動デプロイ | A/B/C
Vercel | 操作画面（HMI）を配信するサーバ | Web アプリ公開 | A/B/C

Railway | 変換処理のバッチサーバ | Excel→JSON 変換 API（FastAPI） | B/C

アカウント: 現状は個人名義。本番（B/C）では会社名義への移行を推奨（退職 · 請求 · 継続性）。
