フローチャート作成ツール — 状況報告

制御フロー図を、Excel のオートシェイプではなく表から自動で描く Web ツールとして試作している（Flowchart Studio）。 装置の手順表を貼り付けるとフロー図ができ、保存 · 画像出力ができる。

いまの状況

  1. 1. 経緯：作成方法を調査し、自分がベストだと考える形で叩き台を作成した。
  2. 2. 進捗：試作版は動作中。個人検証用の無料枠で公開している。
  3. 3. 位置づけ：本番運用の前提は未確定 · 方針確定後に開発を進める。
  4. 4. 本番運用：課内本番には外部の有償クラウドサービス（後述 4 種）が必要になる見込み。
  5. 5. 有償が難しい場合：無償でできる範囲に絞り、運用方法を再検討する。

触る：flowchart-studio-dun.vercel.app （手順 · ログインは 02_触ってみる手順.txt）

なぜ Web アプリにしているか

Excel オートシェイプで作る案もあるが、調査の結果 Web 版を選んだ。

所在 · 探しやすさ

Excel 貼付はシートが散らばり、作った図がどこにあるかわからなくなりやすい。Web なら一か所に集約し、ブラウザから一覧できる。

共有 · 参照

他者が作ったフローを探しにくい。Web + 保存庫なら課内で参照しやすい。

修正の手間

オートシェイプは削除 · 貼付の手作業が多い。Web は表を直して再生成するだけで短い。

配布 · 版の揃え

PC ごとの配布 · 版揃えが大変。Web なら一か所修正で全員が同じ版を使える。

なぜ有料サービスが必要か（本番運用の場合）

いまの URL は個人検証用の無料枠（月 0 円）。叩き台の確認には足りるが、課内の正式ツールとして使い続けるには向かない。

（判断依頼ではありません · 為替 150 円目安）

上記有償プランの合計 月 約 $50（約 7,500 円） — ログインあり · 推奨構成の上限。

ベストと考える仕組みを実現する場合に、実現可能性が高い組み合わせ。本番に載せる機能を絞れば、目安はさらに下がる。

保存するデータ：フロー表 · 社内番号 · 装置名 · PLC コメント等（フローチャートに必要な社内設計データ）。客先名 · 契約情報等の社外秘は含めない想定。

ログイン：課内で使うツールとして認証が必要。認証とデータ保存に Supabase を使う想定（有償プラン検討時）。
