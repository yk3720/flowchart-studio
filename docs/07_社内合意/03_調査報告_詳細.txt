2. 調査結果 vs 作成者推奨
================================================================================

【調査結果】
・表駆動 Web 版は実用に近い叩き台として動作する
・無料枠（構成 A）で PoC は可能だが、本番運用には制約が多い
・本番 Web 運用には月 $25〜50 程度のランニングコストが必要
・完全無料を維持する場合はデスクトップ（構成 D）が現実的
・推奨構成（B）を進めるには有償 SaaS の利用判断が前提になる

【作成者推奨】
構成 B（月 $50）— 本番 · ログイン認証 · FastAPI 込み

【構成 B を推奨する理由（詳細）】

(1) 現行 Web + FastAPI の一体運用
  調査の結果、表駆動 · 自動レイアウトの Web 版に FastAPI（xlsx 正規化）を
  組み込む構成が、作者の作業フローに最も合う。PC 専用 exe への依存を減らし、
  ブラウザから装置 xlsx を選んで変換 → 取込まで完結できる。

(2) 正式運用にはログイン認証
  会社として正式ツールとして運用するなら、ユーザー管理 · データの所有者
  分離が必要。共用 admin アカウントは検証（PoC）用であり、本番では
  Supabase Auth による個人ログインが望ましい。ログイン要否は B/C で
  相談可能だが、正式運用なら B を推奨。

(3) FastAPI 追加コストは小さい
  Railway Hobby は月 $5 程度。Web 本番（B/C）では影響が小さいため、
  採用する前提とした。

(4) PLC コメントとフローの連携
  保存データには PLC コメント（またはフロー表の文言）が含まれる見込み。
  PLC コメント ↔ フローチャートを対応づけないとツールの価値が下がる。
  どちらを正本にするかは今後決めるが、リンクを維持するにはクラウド上の
  永続保存 · 認証付き Web が前提になる。

(5) 完全無料では推奨構成に届かない
  推奨（B）を進めるには Vercel Pro · Supabase Pro · Railway の有償利用が
  必要。上司判断の焦点は「無料（A/D）か 有償 Web 本番（B/C）か」の二択。

(6) 年度テーマとの整合
  個人テーマ「フローチャート作成ツール実用化 · 1装置分」に向け、
  現状 PoC（A）から本番（B）へ移行するのが自然。

【Web版を選んだ理由（デスクトップ Excel+オートシェイプとの比較）】

調査の過程で、従来のデスクトップ方式（Python+Excel · オートシェイプ）と
Web 版を比較した。Web 版を採用した主な理由は以下のとおり。

(W1) 所在がすぐわかる · 探す手間が減る
  デスクトップ版は Excel シートにフローを貼り付けるため、シートや貼付位置に
  多くの場所を取り、管理が煩雑になる。作ってもどこにあるかわからなくなり、
  運用が難しくなる。
  Web 版はデータを Web 上に集約し、アプリ（ブラウザ）を開けば一覧から
  アクセスできる形にできる。

(W2) 他者が作ったフローの参照
  Excel 分散では、他の人が作ったフローを参照しようとしても探すのが大変。
  Web + データベースに保存すれば、他者のフローチャートを見に行く操作が
  大幅に簡単になる。

(W3) 作り直し · 修正の工数
  Excel オートシェイプ方式は、フローを作り直すときに図形の削除 · 貼付など
  工数がかかりすぎる。
  Web 版は表駆動（表を直して再生成）のため、作図 · 修正の手間がはるかに少ない。

(W4) バージョン管理 · 配布
  デスクトップアプリは、バージョン管理が大変で、配布の手間もある。
  Web アプリは一箇所を直せば全員がすぐ使える — 配布 · 更新が楽なのが
  大きなメリット。

→ 以上より、方式選択として Web（構成 B/C）を推奨。完全無料を優先する場合のみ
  デスクトップ（構成 D）を検討する（§8 参照）。

-----|--------|-----|---------|------|----------

（以下、内訳 · 補足は従来どおり）

構成 B の内訳:
  Vercel Pro: $20/席/月（$20 利用クレジット込み · 1 TB 転送等）
  Supabase Pro: $25/組織/月（Micro 1 プロジェクト · 7日バックアップ · 停止なし）
  Railway Hobby: $5/月（$5 リソースクレジット込み · 軽量 FastAPI 想定）

構成 C の補足:
  Neon Free は PoC 向き（0.5GB · 5分でスケールゼロ · CU 時間上限）
  本番なら Launch 従量（$0.106/CU-hour 等）で月 $5〜15 程度を想定
  認証なしのため、アクセス制御 · ユーザー別データ分離は別途設計

追加コスト（任意）:
  Vercel デプロイ席追加: +$20/席/月
  Supabase PITR: 約 $100/月（本調査では未含）
  独自ドメイン · 従量超過 · 為替変動

4. 各サービスの説明
================================================================================

--- GitHub ---
役割: ソースコードのバージョン管理 · Vercel 連携による自動デプロイ
Studio: flowchart-studio リポジトリ本体
料金: 無料プランで private リポ可（Organization も $0 から）
本番論点: 会社 Organization 化 · 退職時の引き継ぎ
参照: https://github.com/pricing

--- Vercel ---
役割: Next.js Web アプリのホスティング（CDN · HTTPS · 自動デプロイ）
Studio: ブラウザ操作画面の公開先
料金: Hobby $0（非商用・個人）/ Pro $20/席/月
制約: Hobby は商用利用不可（有給業務での本番運用は Pro 推奨）
参照: https://vercel.com/docs/plans
      https://vercel.com/docs/limits/fair-use-guidelines

--- Supabase ---
役割: PostgreSQL DB · 認証（Auth）· Row Level Security
Studio: フローデータ永続化 · ログイン · ユーザー別データ
料金: Free $0 / Pro $25/月
制約: Free は7日非アクティブで pause · 自動バックアップなし · 500MB
参照: https://supabase.com/pricing
      https://supabase.com/docs/guides/platform/free-project-pausing

--- Railway ---
役割: FastAPI（Python）の常時稼働ホスト
Studio: 装置 xlsx → import.json 正規化 API（B/C のみ）
料金: Hobby $5/月（$5 クレジット込み · 超過分は追加課金）
参照: https://railway.com/pricing
      https://docs.railway.com/pricing/plans
